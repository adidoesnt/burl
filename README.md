# Burl

Burl is my implementation of a suite of Unix command-line tools. I developed each tool in the suite while reading through the corresponding chapter in [Command Line Rust](https://www.goodreads.com/en/book/show/60167043-command-line-rust) by Ken Youens-Clark.

The official GitHub repository that comes alongside the book can be seen [here](https://github.com/kyclark/command-line-rust).
